# Logos du fond « Road to X/ENS »

Fichiers officiels, conservés à l'identique. La transparence est appliquée par CSS uniquement dans la page `/reussir-sa-kholle` ; les images de fond sont décoratives et ignorées par les lecteurs d'écran.

- `polytechnique.png` : version RVB du [kit média de l'École polytechnique](https://www.polytechnique.edu/presse/kit-media), [archive officielle des logos web verticaux](https://www.polytechnique.edu/sites/default/files/content/pages/documents/2022-02/Kit_logo_web_vertical.zip), entrée `Kit_logo_web_vertical/X-IPParis - RVB.png`.
- `ens-psl.png` : version bleue du [logotype de l'ENS](https://www.ens.psl.eu/logotype-de-l-ens), [fichier PNG officiel](https://www.ens.psl.eu/sites/default/files/logo_ens_psl_petit_rvb_bleu.png).

La page de l'ENS précise que l'usage de son logotype est subordonné à l'accord de sa direction de la communication. Cette condition est à prendre en compte avant une diffusion publique. Les noms et logos désignent ici les écoles visées par la préparation ; aucun partenariat institutionnel n'est déclaré.

Sources consultées le 27 septembre 2026.
